# Hello OSS Project

## Giới thiệu
Hello OSS Project là dự án mã nguồn mở đơn giản viết bằng ngôn ngữ C, có chức năng in ra dòng chữ "Hello Open Source!".

## Mục tiêu
- Làm quen với Git và GitHub.
- Thực hành xây dựng một dự án mã nguồn mở.
- Học cách viết tài liệu và sử dụng giấy phép OSS.

## Công nghệ
- Ngôn ngữ: C
- Trình biên dịch: GCC
- Quản lý mã nguồn: Git và GitHub

## Hướng dẫn build và chạy

Biên dịch:

```bash
gcc main.c -o hello
```

Chạy trên Windows PowerShell:

```powershell
.\hello.exe
```

Kết quả dự kiến:

```text
Hello Open Source!
```
